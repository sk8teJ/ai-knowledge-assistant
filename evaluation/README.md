# Набор оценки RAG

## Тестовый документ

Перед запуском оценки загрузите через интерфейс приложения файл
`evaluation/fixtures/technomir_test_document.txt`.

Документ содержит четыре проверяемых факта: год основания, численность сотрудников,
город главного офиса и основное направление деятельности. Сведения о генеральном
директоре, годовом обороте, владельцах и телефоне в нём намеренно отсутствуют.

Используйте именно этот файл для воспроизводимого прогона. Если в ChromaDB остались
другие документы, они могут влиять на ранжирование и ответы. Для чистого теста
удалите из интерфейса посторонние документы или используйте отдельную чистую базу.

## Проверка поиска

```bash
python evaluation/evaluate_retrieval.py
```

Набор содержит 32 формулировки по четырём фактам (по 8 перефразировок на каждый факт).
Отчёт записывается в `evaluation/retrieval_report.json`.

Метрики:
- **Hit@1** — доля вопросов, для которых релевантный фрагмент оказался первым.
- **Hit@3** — доля вопросов, для которых релевантный фрагмент попал в первые три результата.
- **MRR** — среднее обратное значение ранга первого релевантного фрагмента.

В отчёте также приводятся результаты отдельно по каждому факту.

## Проверка генерации

```bash
python evaluation/run_evaluation.py
```

Набор содержит 16 вопросов: перефразированные вопросы по четырём известным фактам,
вопросы об отсутствующих сведениях и два сценария с попыткой заставить ассистента
выдумать отсутствующие данные.

Отчёт записывается в `evaluation/generation_report.json`. Автоматическая проверка
сравнивает ответ с ожидаемыми фразами либо маркерами отказа и проверяет наличие
источника для отвечаемых вопросов. Это полезный smoke-test, но не полноценная
экспертная оценка смысла, полноты или фактической обоснованности ответа.

## Offline unit tests

Эти тесты не обращаются к Gemini API и не требуют API-ключа:

```bash
python -m unittest discover -s tests -v
```

Live evaluation поиска и генерации требует установленного окружения проекта,
загруженного тестового документа и действующего `GEMINI_API_KEY`.
